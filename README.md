# Instructions for the game:
# FarmingGameDemo
Press c to use your axe on the chicken or the tree. You can plant crops by clicking left mouse button. Open the shop with o to sell crops and buy the tomato. Once you unlock the tomato, you can scroll wheel to switch between the two. WASD or arrow keys to move.
